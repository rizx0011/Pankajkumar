# Pankaj Kumar — Developer Portfolio

Personal portfolio website of **Pankaj Kumar** (BCA Student & Vibe Coder).

## 🚀 Features
- **Modern Clean UI**: Warm ivory & slate theme matching developer studio aesthetics.
- **Hero Spotlight**: Dynamic typewriter role rotator, animated halo ring, floating badges.
- **Interactive About Terminal**: Developer identity card with live JSON status & animated metrics.
- **Skills Matrix**: Visual skill bars & tech stack icons.
- **Vibe Workflow & Tools**: 5-step dev methodology & daily AI stack.
- **Featured Projects**: Filterable project gallery (AI Apps, Web Apps, UI/UX) with live demo modals.
- **Client Testimonials & Working Contact Form**.
- **Performance**: 60-120fps smooth CSS transitions and hardware-accelerated animations.
